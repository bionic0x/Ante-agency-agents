# NETRUNNER FOUNDATION v0.2 — APEX × CRASHOVERRIDE × HACK THE PLANET

**Status:** Documentary consolidation / offline synthetic research. **Source corpus:** 27 user-supplied documents (9 prior + 18 additional). **Decision:** `PROCEED_WITH_CONDITIONS` for research and design; `HOLD` for live DeFi, financial services, custody, tokens/NFT distributions, third-party intervention and production authority.

## Governing object

Assess whether a reproducible, evidence-first **Solana + Arbitrum One MEV observability and protocol-risk research product** can help an accountable risk team recognize adverse ordering, degraded valuation inputs, interruption and unresolved recovery exposure. Retain the 1990s cyberpunk terminal and gamified education as an interface, not an execution authority or statement of returns.

## Non-object

The source documents also describe RAT infiltration, nonconsensual surveillance, wallet obfuscation to avoid attribution, engineered liquidations, sandwich attacks against users, coordinated price moves, spoofing, manipulative sentiment operations, evidence destruction, regulatory avoidance and invented returns. These are **not implementation requirements or authorized work**. Some remain eligible as abstract historical *threat scenarios* in isolated, non-executing simulation.

## Ante dependency, not duplication

The existing `strategy/htp-gate0/` and `strategy/runbooks/scenario-htp-gate0-solana-arbitrum.md` remain authoritative for network-specific Gate 0 and are unchanged by this proposal. G1/P1/D1/D3/S1/E1-SOL/E1-ARB/G2 stay subject to their established ownership and evidence contracts; add `specialized-strategic-assurance-lead` for the seven coherence tests. **One chain's evidence never upgrades the other.** No agent profile, documentation change or PR creates a live-execution permission.

## Research-only dependency flow

```text
Public/authorized historical events or synthetic fixtures
  -> source provenance and input validation
  -> network-specific SOL / ARB adapters
  -> detection hypotheses + alternatives + missingness
  -> D1 provenance -> E1-specific review -> S1 challenge -> D3 claim audit
  -> G1 strategic packet + named human authority (pending)
  -> versioned dossier/hash
  -> CRASHOVERRIDE / HACK THE PLANET UI

NO signer, trader, custodian, RAT, manipulative bot, or production action path.
```

## Product milestones

- **G0:** source/claim inventory, object/non-object, legal and safety boundaries.
- **G1:** offline, deterministic, synthetic replay and evidence-console usability. Existing local NETRUNNER v0.1 baseline reports 17 unit tests; this PR **does not** import or independently re-run that code.
- **G2:** independently reviewable historical reconstruction, separately for Solana and Arbitrum.
- **G3:** read-only shadow pilot after rights and human security/legal review.
- **G4:** controlled observability product with measured useful decision outcomes; no automatically inherited trading authority.
