# Larkfield Booking 5.8.0 — release notes (synthetic)

- Faster slot search on the booking page.
- Patients can reschedule from the reminder link without logging in again.
- Reminder SMS and lock-screen push now include the appointment type, to cut
  confusion about which appointment the reminder refers to
  (for example "Reminder: Oncology follow-up, Tue 14 Oct 09:30, Larkfield
  Riverside").
- Clinic staff can bulk-cancel a session and notify patients in one step.
- Updated cookie banner text.
